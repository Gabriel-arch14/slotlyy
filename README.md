## Какво може

**За клиентите**
- Каталог с категории, търсене, филтри по марка и цена, сортиране
- Страница на продукт с галерия, характеристики и отзиви (по един отзив на продукт)
- **Любими** — сърце на всеки продукт и отделна страница „Любими“
- Количка, която остава и след презареждане
- Поръчка с доставка до **офис на Еконт в Габрово** (падащо меню, офисите идват на живо от Еконт)
- Промо кодове, безплатна доставка над 100 €
- Регистрация, вход и история на поръчките
- Имейл с потвърждение на поръчката

**За собственика (скрит админ панел на `/admin`)**
- Табло с оборот, поръчки, най-продавани и ниска наличност
- Добавяне, редакция и изтриване на продукти
- **Масов импорт от Excel** — шаблон с падащи менюта, експорт на всички продукти и импорт обратно
- Управление на статуса на поръчките
- Имейл известие за всяка нова поръчка

**Сигурност**
- Вход с httpOnly бисквитка, CSRF защита, ограничение на опитите за вход и поръчки
- Паролите са хеширани (bcrypt), тайните ключове са само в `server/.env`
- Цените и наличностите винаги се проверяват на сървъра

## Технологии

| Част | Технология |
|------|-----------|
| Сайт | React 18 + TypeScript, Vite, lucide-react |
| Сървър | Node.js 22+ + Express + TypeScript (tsx) |
| База данни | SQLite, вградена в Node (`node:sqlite`) — без отделен сървър |
| Имейли | [Resend](https://resend.com) |
| Excel | exceljs |
| Публичен достъп | Cloudflare Tunnel |

## Стартиране на компютъра

Нужен е [Node.js](https://nodejs.org) 22 или по-нов.

```bash
npm run install:all                      # само първия път
cp server/.env.example server/.env       # и попълни стойностите в него
npm run dev                              # пуска сървъра и сайта заедно
```

Отвори http://localhost:5173 . При първото пускане базата се създава сама с примерни продукти.

Админ панел: http://localhost:5173/admin — имейл `admin@slotlyy.bg`, паролата е `ADMIN_PASSWORD` от `server/.env`.

## Пускане онлайн (безплатно, от твоя компютър)

Магазинът може да се отвори за целия интернет директно от компютъра, без хостинг:

```bash
npm run online
```

или двоен клик на **`Пусни-онлайн.bat`**.

Скриптът компилира сайта, пуска сървъра и отваря безплатен [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/). След няколко секунди показва публичен адрес от вида `https://нещо-случайно.trycloudflare.com`.

- Нужен е `cloudflared`: `winget install --id Cloudflare.cloudflared`
- Сайтът работи, докато прозорецът е отворен и компютърът е включен
- Адресът се сменя при всяко пускане
- Спри `npm run dev` преди това — двете ползват порт 4000

## Настройки (`server/.env`)

| Променлива | За какво е |
|-----------|-----------|
| `RESEND_API_KEY` | Ключ за изпращане на имейли |
| `SHOP_EMAIL` | Фирменият имейл, който получава известие за поръчка |
| `MAIL_FROM` | Подател на имейлите |
| `JWT_SECRET` | Таен ключ за входовете (дълъг случаен низ) |
| `ADMIN_PASSWORD` | Паролата за `/admin`. Смени я тук и рестартирай |
| `SITE_URL` | По желание — фиксиран адрес за линковете в имейлите |

> **Имейли до клиенти:** без потвърден домейн Resend праща само до собствения ти имейл. За да стигат до клиентите, добави домейн в [resend.com/domains](https://resend.com/domains) и смени `MAIL_FROM`.

## Полезни команди

| Команда | Какво прави |
|---------|-------------|
| `npm run dev` | Режим за разработка (сайт на :5173, API на :4000) |
| `npm run online` | Пуска магазина публично през Cloudflare Tunnel |
| `npm run build && npm start` | Production режим на http://localhost:4000 |
| `npm run reset-db` | Изтрива базата — при следващото пускане се създава наново |
